# v3.9 PR Notes — Full PFR draft-class corpus expansion (1936 → present)

**Branch:** `ada/v3.9-full-pfr-corpus`
**Trigger:** Phil DM 2026-06-01 — "2440 long-arc comp pool feels under-pulled; pull every PFR-drafted player so the active rankings get more dynamic."

## What changed

### Code
1. `scripts/build_pre1999_corpus.py`
   - Default range expanded from 1980-1998 → **1936-1998**.
   - Added `--from-year` / `--to-year` CLI args (existing args still work).
   - Pre-1970 years (no PFR fantasy table) fall back to building the universe from passing/rushing/receiving rows directly; we compute `fantasy_points_ppr` ourselves using `dynasty.scoring_rules.score_season(..., "sf_ppr")`.
   - Added position inference for pre-1970 rows (rushing/receiving tables don't carry a `pos` field on the old PFR pages):
     - ≥ 20 pass attempts → QB
     - ≥ 50 carries with rush volume ≥ 3× receiving volume → RB
     - ≥ 15 receptions and recs > carries → WR
     - Falls back to RB / WR by volume threshold.
     - TE is intentionally NOT inferred pre-1970 (TE wasn't a stable fantasy position concept and the tables don't distinguish WR vs TE).
   - Added 1960-1969 AFL and 1946-1949 AAFC league coverage (PFR's `/years/{YEAR}_{LEAGUE}/{table}.htm`). This pulls O.J. Simpson's 1969 rookie year (Buffalo / AFL), Lance Alworth (SD / AFL), Otto Graham (Cleveland / AAFC), etc.

2. `src/dynasty/sources/pro_football_reference_seasonal.py`
   - `fetch_season_table()` and `_season_cache_path()` now accept `league=` ("NFL" / "AFL" / "AAFC"). Cache lives at `data/pfr_cache/{year}/` (NFL) or `data/pfr_cache/{year}_{league}/` (AFL / AAFC).
   - Reordered `WAYBACK_TIMESTAMPS` so `2025` is tried first — older PFR pages (1937, 1940-1942, etc.) only have valid snapshots in the 2025 captures.
   - Reduced default `max_retries` from 5 → 3 (faster fall-through to the next Wayback timestamp when a snapshot is stale 403).

3. `scripts/refresh_pfr_draft_classes.py`
   - Added `--all-history` flag (1936 → present) and `--from-year` / `--to-year` range args. Default behaviour (2022-2026) unchanged.

### Data

- v3.0–v3.8 penalty scaling, comp-floor, per-position VORP, retired-early flag, etc. — unchanged. Only the **universe** the filters operate on has grown.

## Caveats / honest accounting

- The long-arc pool growth from this expansion is **conservative**. Most pre-1980 careers are 4-6 seasons long and may not clear the 8-season threshold, but they DO clear the "retired-through-2022" threshold trivially. So every distinct pre-1980 player with a qualifying season-line lands in long-arc.
- Some pre-1965 names will be misclassified as WR when they were really TEs (e.g., Mike Ditka). The era effectively didn't have a stable TE distinction; rather than guess we accept this and document it. If Phil wants TE bio-driven backfill for that era it's a small follow-up.
- Pre-1970 raw stat tables don't track targets, fumbles_lost, or 2-pt conversions. Fantasy point totals are computed from yardage + TDs only, which understates pass-catcher production slightly. The arc-based engine uses career-arc *shape* + era pace, not raw fantasy points, so this affects ranking less than it'd appear.
- Many PFR pre-1970 snapshots only have 200 responses under specific Wayback timestamps. Our retry-fallback handles this, but some years (1940 receiving, 1941 receiving) may end up with partial data when all 4 timestamp attempts 403/refuse. The cache persists what we did get so subsequent runs heal further.
